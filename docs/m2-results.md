# M2 결과 — 개러지·경제

측정: 2026-11-03, Pleos Connect v2.1 에뮬레이터(Android 14, user 빌드, 앱은 user 10, 앱 창 1682×1210, density 1.0), 브랜치 `feature/m2-garage`. 계획은 `현기차_경진대회/.claude/plans/downshift-m2.plan.md`. 원본 수치와 캡처는 `docs/m2/` (`cpu.txt`, `memory.txt`, `frames.txt`, `persist.txt`, `sound_check.txt`, `01`~`09` 캡처), 재현은 `bash tools/garage.sh flow|persist|cpu|mem|frames`.

상태: 계획한 12개 작업 완료. **남은 일:** 사용자 확인(화면·미리 듣기 청음), 좁은 화면(1칸) 레이아웃은 에뮬레이터 창이 넓어 실제로 보지 못함.

## 무엇이 되나

- 개러지가 첫 화면이다. 시안(`Main.dc.html`)의 2칸 구성: 왼쪽은 번호판·3D 엔진 무대·점화 순서·소리 성향 막대·시동 버튼, 오른쪽은 5개 탭(엔진/흡기/배기/변속기/세팅)과 부품 카드, 아래 동작 줄
- 부품 카드: 사진(엔진은 3D 렌더), 이름, 단계 눈금, 소리 설명, 상태(장착됨 / 보유 / `N P · 해금 가능` / `N P · 약 Xkm 더` / 고르는 중 / 한정 콜라보). 성능 수치는 없다
- **미리 듣기**: 잠긴 부품도 정차 중이면 그 부품을 끼운 빌드로 짧은 각본(엔진: 레브, 흡기: 부스트와 블로오프, 배기: 기어 물린 오버런과 팝콘, 변속기: 업·다운시프트와 블립)을 들려준다. 엔진이 꺼져 있었으면 시동 2초를 앞에 붙이고, 끝나면 장착 빌드와 원래 시동 상태로 돌아간다. 다시 누르면 멈춘다
- 포인트 지갑: 해금하면 잔액이 줄고, 장착하면 엔진음이 다음 블록부터 바뀐다. 상태가 바뀔 때마다 바로 저장되고 강제 종료 뒤에도 남는다
- 3D 무대: 엔진마다 24장 회전 컷. 끌어서 돌리고, 탭을 고르면 그 부품이 보이는 각도로 짧은 쪽으로 돈다. 붙는 자리에 점·지시선·칩("미리보기"는 점선, "장착됨"은 실선), V8 슈퍼차저와 V12 트윈 터보는 겹침판으로 서서히 나타난다. 장착하면 무대가 살짝 기울고 자리가 한 번 빛난다
- 세팅 탭: 팝콘 강도(0~5), 레드라인(엔진 레드라인 ±500rpm을 100씩, 절대 rpm으로 표시), 볼륨(10%씩). 바꾸는 즉시 엔진에 적용. 시연용 버튼 2개(포인트 +1,000, 처음 상태로)
- 주행 중(기어 D·R 또는 1km/h 이상)에는 헤더가 "D 주행 중"으로 바뀌고 해금·장착·미리 듣기·세팅이 잠기며 "정차 중에만 바꿀 수 있어요"를 보인다
- 엔진은 앱 전체가 하나를 공유한다(`EngineHost`). 사운드 랩·프로브는 화면 위 개발용 줄에 남겼다
- adb: `garage --es action add|reset|unlock|equip|preview|tab` (PT 리허설·캡처용)

| 탭 | 5개 | 그대로 |
| 세팅 조절 | −/+ 버튼, 팝콘 0~5, 레드라인 ±500 (100씩, 절대 rpm), 볼륨 10%씩 | 그대로. 끝값에서 버튼이 흐려짐 |

| 시연 버튼 | 세팅 탭에 늘 보임 | 그대로 |
| 4번째 엔진 | 자리 카드 | "다음 엔진 · 고르는 중", 미리 듣기 없음 |

| 저장 | SharedPreferences JSON | 그대로 (`garage`/`state`, 기본값도 모두 기록) |

## 계획과 달라진 점

| 계획 | 실제 | 이유 |
|---|---|---|
| 번호판은 장착 빌드 | 미리보기 중엔 미리보기 빌드의 번호판 (계획대로, 시안과는 다름) | 막대·무대와 같은 빌드를 보여 줌 |
| 엔진이 꺼져 있어도 매 블록 믹서를 돌림 | 엔진이 멈추고 0.5초 동안 울림이 없으면 0을 씀 (`EngineRuntime.quiet`) | 개러지 대기 CPU 5.7% → 3.0%. 무음 합성에만 1코어의 2.5% |
| 엔진 꺼짐 콘솔 폴링 100ms | 200ms | 같은 이유. 엔진이 꺼져 있으면 기다릴 소리가 없다 |
| 미리 듣기 중에도 콘솔 빠른 폴링 | 각본이 페달 대신이니 느린 폴링 | 미리 듣기·회전 22.7% → 15.9% |
| 회전은 프레임 번호만 바꿈 | 무대·rpm 표시·길게 누르기 채움을 각자 그래픽 레이어로 | 레이어가 없으면 한 칸 돌 때마다 개러지 전체를 다시 기록했다 (메인 스레드 10%) |
| 회전 컷은 지금 엔진 두 벌만 | 무대가 엔진별로 24장을 한 번에 디코딩해 들고 있고, 엔진이 바뀌면 버림. 카드·hero·칩 사진만 16MB LRU | 계획 그대로의 효과, 구현 방식만 정함 |
| `EngineAudioOutput.inputs()` | 블록 길이(초)를 받음 | 미리 듣기 각본이 오디오 시간으로 흐르게 |
| adb `preview`는 재생만 | 카드도 고름 | 캡처에서 무엇을 듣는지 보이게 |
| 개발 탭 | 개러지 위 40dp 줄(개러지 · 사운드 랩 · 프로브) | 사운드 랩·프로브를 남기라는 제약. PT 때 숨기는 건 M4 시연 모드 |

미리 듣기 각본 점검(엔진 3 × 변속기 3 × 배기·변속기 각본): 모든 조합이 업·다운시프트를 낸다. 다만 **V12 + DCT·수동은 변속기 각본에서 업시프트가 한 번**이다(레드라인 8,000이라 변속점이 늦음). 각본 상수는 계획의 규칙(스로틀 0.8, 3.6초) 안이라 그대로 뒀다.

## 확인하지 못한 것

- 좁은 화면(폭 1,200dp 미만) 1칸 레이아웃: 코드는 있지만 에뮬레이터 창이 1,682dp라 화면으로 보지 못했다
- 장착 때 기울기·빛남 애니메이션: 코드 경로는 돌았지만(오류 없음) 160ms짜리라 캡처로 잡지 못했다
- TalkBack: 카드·버튼·탭에 접근성 라벨("미리 듣기: V8", "팝콘 강도 높이기" 등)을 달았지만 화면 낭독기로 들어 보지 않았다
- 실차: 주행 중 화면 가림, 프레임 시간, 기어·차속 신호

## 남은 일과 M3로 넘기는 것

1. 사용자: 개러지 화면과 미리 듣기 청음 확인. 음색 조율(M1 보류)은 그대로 보류 중
2. M3 포인트 적립: 주행 결산에서 `GarageViewModel`이 아닌 저장소 쪽(`Garage.addPoints` → `GarageStore.save`)으로 넣고, 개러지는 다시 열 때 읽는다. 지금 지갑은 시연 버튼으로만 늘어난다
3. M3 시동 화면: 링·바늘 스윕이 있는 화면은 개러지의 '이 빌드로 시동'을 대신해서 들어간다
4. M4: 시연 모드에서 시연 버튼과 개발 탭 줄 숨기기
5. 글꼴: Barlow Semi Condensed는 파일 다운로드라 사용자 승인 뒤 교체
6. 부품 사진(Figma AI) 약관 확인은 제출 전 (`docs/m2/parts_source.md`)
7. 4번째 엔진: 소리는 실시간 합성으로 바로 넣을 수 있지만 3D 렌더가 있어야 개러지에 들어간다
